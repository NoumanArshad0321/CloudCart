About Project

CloudCart — Cloud-Based E-Commerce Product Image Storage System

A university Cloud Computing lab project. It demonstrates how an e-commerce application runs in the cloud: the app itself is hosted on Render (a cloud platform) instead of on one local computer, and product images are stored on the server that runs the app, while product information is stored in a SQLite database on the same server.

Why host on Render?
  • Available anywhere: anyone with the link can open the shop — it does not depend on your laptop being on.
  • No setup on your computer: Render runs the app on its own servers; you just push the code to GitHub.
  • Free for a lab: the free tier needs no credit card and is enough for a demo.
  • Real cloud behaviour: the service sleeps when idle and its disk is temporary — you learn how cloud hosting actually behaves, limits included.
Local computer vs cloud hosting
  • Local Mode (running on this computer): the app and its images live on your machine. Simple, but nobody else can reach it and everything is lost if the machine is off or replaced.
  • Cloud hosting (Render): the app runs on Render's servers and is reachable from anywhere. But on the free tier the server's disk is ephemeral — images and the database can be lost on a restart or redeploy. That is why a production system stores files in object storage instead of on the web server's disk (see the Cloud Storage page).
Technology stack

Python + Flask (backend) · SQLite (product data) · Server-disk image storage (instance/uploads/) · Bootstrap 5 (frontend) · Gunicorn (production server) · pytest (tests) · Render (free cloud hosting).
